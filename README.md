# Arquitectura del proyecto

La aplicación sigue una arquitectura frontend estática orientada a componentes visuales.

```text
┌──────────────────────────────┐
│          HTML UI             │ ← Estructura principal
├──────────────────────────────┤
│            CSS               │ ← Estilos y diseño visual
├──────────────────────────────┤
│        JavaScript            │ ← Interactividad y lógica
├──────────────────────────────┤
│      Responsive Layout       │ ← Adaptación móvil
├──────────────────────────────┤
│      Assets & Media          │ ← Imágenes e íconos
└──────────────────────────────┘
```
